# Securing TEEs against re-entry attacks

This folder contains the implementation of a simulated bitstream for the conjugate coding implementation described in the blog post [Securing TEEs against re-entry attacks](https://blog.neverlocal.com/tee-re-entry/), based on a heralded photon implementation where each herald-data photon pair carries a single bit of the secret table.

## Code

The implementation consists of two Arduino sketches:

- [`sender.ino`](./sender/sender.ino): Written for the ATmega328p chip, it simulates the bitstream that would be generated by the quantum hardware, using realistic noise parameters but slowing down the process for testing purposes.
- [`receiver.ino`](./receiver/receiver.ino): Written for the ESP32 chip, it provides a sample implementation of a decoder for the bitsream.
